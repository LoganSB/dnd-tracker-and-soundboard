# DND Tracker: notes for the coding assistant

- Read `LINKED-COMPONENTS.md` at the start of every session. It lists which parts of this app are linked (for example: a new
  card type on the campaign tracker must also appear in the canvas click menu) and the end-of-prompt "link check" procedure.
- Do the link check as the LAST step of a prompt, once, and ask the user before applying anything it finds.
